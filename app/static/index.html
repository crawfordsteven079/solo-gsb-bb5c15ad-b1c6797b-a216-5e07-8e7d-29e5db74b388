解析诊断

    2. 报文结构（可编辑）

    直接修改头部、正文、boundary、preamble/epilogue；叶子节点可切换 Content-Transfer-Encoding（base64 / quoted-printable 等）。未改动的节点按原字节还原。

    CID 引用检查

    仅静态扫描 text/html（合法 UTF-8）叶子的 src / href 中 cid: 引用，不执行、不加载任何资源。 每个引用只在最近的 multipart/related 祖先作用域内匹配叶子 （嵌套 related 子树排除）；无祖先则报“无作用域”。 Content-ID 去空白与外层尖括号；引用去 cid: 后百分号解码一次，区分大小写。

    3. 附件提取

    递归列出带 Content-Disposition: attachment 或 filename / filename* 参数的叶子。文件名遵循 RFC 2231（扩展值优先，非法时回退普通值）； ZIP 内为 CTE 解码后的字节，已编辑叶子取编辑后的内容。畸形或未知 CTE 的未编辑叶子无法导出。

        5. 样本对比
